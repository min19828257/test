# Samsung-style Demo Site

삼성닷컴(www.samsung.com)과 **유사한 구조와 스타일**의 데모 페이지입니다.  
레이아웃·색감·섹션 구성을 참고한 **연습/포트폴리오용**이며, 실제 삼성 콘텐츠·로고·이미지는 사용하지 않습니다.

## 구성

- **상단 바**: Support, My Account, Special Offers 등 링크
- **메인 네비**: Mobile, TV & Display, Appliances, Tablets & Watches, Explore
- **히어로**: 대표 제품 배너 (Galaxy S25 스타일)
- **제품 그리드**: Galaxy 제품 카드, Home Appliances 카드
- **풀와이드 배너**: TV(Neo QLED) 스타일 섹션
- **카테고리 타일**: Smartphones, TV, Home 등 빠른 링크
- **푸터**: Shop, Support, Company, SNS 링크

## 실행

`index.html`을 브라우저에서 열면 됩니다.

```bash
# 또는 로컬 서버로 열기 (선택)
npx serve .
```

## 참고

- 이미지는 Unsplash placeholder 사용
- 상표·로고는 데모용 텍스트만 사용했으며, 실제 서비스에 삼성 자산을 무단 사용하면 안 됩니다.
